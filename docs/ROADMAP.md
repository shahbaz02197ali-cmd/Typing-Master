# Delivery roadmap

1. Foundation: app shell, guest profile, local typing test, scoring tests and database schema.
2. Typing experience: all durations, curriculum, custom text, content library, marathon checkpoint/resume, history and preferences.
3. Multiplayer: transactional matchmaking, 4-slot rooms, synchronized countdown, shared text, live progress, reconnect handling, bots and multi-browser tests.
4. Competition: verified leaderboards, daily challenges, achievements, certificates and seasons.
5. Admin and language support: protected admin tools, audit logs, analytics, Urdu/Arabic RTL and input normalization.
6. Production readiness: security review, migrations, backups, monitoring, load tests and gradual launch.

The UI in this repository includes starter pages for the product areas. A UI placeholder is not equivalent to a complete backend feature; follow the roadmap and security checklist before announcing global races, certificates or rankings as live.
